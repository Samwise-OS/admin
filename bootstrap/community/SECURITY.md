# Security reporting

Use the affected repository's **Security → Report a vulnerability** private reporting
form. Private vulnerability reporting is enabled during Samwise-OS provisioning and
must be verified before treating this policy as operational.

Include affected versions, a minimal reproduction and the potential impact. Share
sensitive exploit details only through the private report. Do not post credentials,
personal information or undisclosed vulnerabilities in public issues.

If the private report control is unavailable, contact the listed maintainer to obtain
a private channel before sending sensitive details. Public issues may report that the
reporting mechanism is unavailable without disclosing the vulnerability itself.
